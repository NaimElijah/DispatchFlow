How to read it

  • Each step ends with the IDs of the rows it exercises, in parentheses. An alternative is numbered after the step it branches from ("3a."). An alternative that happens later in a person's life, such as a leaver, branches from the last step.
  • DispatchFlow is one black box. The flows say what a person does and sees, not how the system does it. A step-by-step technical flow is written by the code that builds it, not ahead of it.
  • The words follow the ubiquitous language: a customer's location (not "pin"), vehicle, re-optimization, violation, revision and delivery date.
  • An Admin or a Dispatcher can do everything in the phone app that the web app allows (ADR-035). A driver uses the phone app, or the web app online only. The sequence diagrams show the web app, except for the driver.
  • Limits and durations are written as "within the limit". The row holds the value.
